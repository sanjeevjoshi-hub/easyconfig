# EasyConfig - Configuration Management System

## 📌 Project Description
EasyConfig is a Spring Boot based REST API application used to manage configuration data such as API keys, environment settings, and other properties.

## 🚀 Features
- Create configuration
- Read all configurations
- Update configuration
- Delete configuration

## 🛠️ Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## 📂 Project Structure
- Controller → Handles API requests
- Service → Business logic
- Repository → Database interaction
- Model → Entity class

## 🔗 API Endpoints
- GET /configs → Get all configs
- POST /configs → Create config
- PUT /configs/{id} → Update config
- DELETE /configs/{id} → Delete config

## ▶️ How to Run
1. Open project in IntelliJ
2. Run EasyconfigApplication.java
3. Use Postman to test APIs
